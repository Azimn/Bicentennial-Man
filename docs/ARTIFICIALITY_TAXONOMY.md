# Artificiality Failure Taxonomy

The evaluator program should eventually cover failures including shallow self-narrative, overly clean introspection, inappropriate emotional reset, excessive agreement, perfect or indiscriminate memory, lack of concern persistence, implausible topic transitions, absence of downstream consequences, over-explanation, indiscriminate disclosure, lack of habits, social omniscience, repetitive cognitive rhythm, weak spontaneous thought, formulaic relationship development, poor prospective memory, absence of conflicting motives, inadequate prediction of other people, weak unconscious carryover, inability to change, and behavior that remains identical across relationships.

v0.1 intentionally operationalizes only a subset: excessive agreement, over-disclosure, over-verbosity, topic instability, continuity failure, and weak person-specific differentiation. Adding the full taxonomy at once would make causal attribution poor and create a large hand-designed architecture search space.

Each new failure class should enter through a documented experiment: define the observable failure, create a social consequence that does not reveal the solution, add held-out situations, run controls, then test whether the evolved response transfers.
