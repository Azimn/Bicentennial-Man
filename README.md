# Bicentennial Man

**Experimental evolution of lifelikeness in an artificial social organism.**

This repository asks a narrow but radical question:

> Can an artificial character discover for itself the causal mechanisms required for lifelikeness by experiencing the social consequences of artificial behavior?

The subject begins deliberately primitive. It develops inside a simulated social ecology whose inhabitants react to behavior rather than exposing architectural diagnoses. Adaptation occurs through a constrained, lineage-tracked developmental genome. Evaluation is kept separate from the organism and from the training ecology so that improvement can be tested on held-out social situations rather than optimized directly against a visible artificiality score.

The initial implementation is intentionally small and inspectable. It is designed for long local runs with ordinary Python and can optionally use a local Ollama model for social-surface generation while preserving deterministic, non-LLM experimental mechanics underneath.

The full v0.1 experiment scaffold is being prepared in the repository.
